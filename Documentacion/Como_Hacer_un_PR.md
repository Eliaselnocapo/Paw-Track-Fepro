***************Esto es exlusivamente cuando hagas un cambio directo al main mamahuevaoso****


Para pasar los cambios de develop hacia main (Producción), sigue estos pasos exactos:

Paso 1: Abre el Pull Request en GitHub
1. Ve a la página de tu repositorio en GitHub desde el navegador.

2. Haz clic en la pestaña Pull requests (está en la barra superior, al lado de "Code" e "Issues").

3. Haz clic en el botón verde que dice New pull request.

Paso 2: Configura la dirección del cambio
1. Verás dos botones desplegables que dicen base y compare.

2. En base (la rama que va a recibir los cambios), selecciona main.

3. En compare (la rama que tiene tu código nuevo), selecciona develop.

4. GitHub te mostrará un mensaje en verde que dice "Able to merge".

Paso 3: Crea y aprueba el Pull Request
1. Haz clic en el botón verde Create pull request.

2. Ponle un título claro, por ejemplo: "Actualización del README base".

3. Haz clic de nuevo en Create pull request.

Como tú eres el administrador y acordamos que no tendríamos bloqueos de aprobación para ir rápido, simplemente baja un poco y haz clic en el botón verde gigante que dice Merge pull request y luego en Confirm merge.
